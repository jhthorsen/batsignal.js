Keyboard shortcut plugin

This plugin maps keys to named functions with data-kbd="h,ArrowLeft:somefunction; Escape:otherfunction". Separate keys with commas and mappings with semicolons. Prefix a key with modifiers such as Ctrl+, Alt+, Shift+, or Meta+ (for example, Ctrl+h:somefunction).

Press Ctrl+H, Ctrl+ArrowLeft, or Escape to see the global key events.

The plugin ignores repeated keydown events and shortcuts originating in editable controls. Each listener uses the element's batsignal lifecycle signal, so it is removed when batsignal destroys that element.
